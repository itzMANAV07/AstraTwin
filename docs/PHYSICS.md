# Prototype physics and health model

All values in this document describe the synthetic browser demonstration. They are prototype assumptions, not validated engine maps.

## Atmosphere and expected channels

Below 11,000 m, the atmosphere helper uses the ISA troposphere approximation:

```text
T = max(216.65 K, 288.15 K - 0.0065 K/m * min(h, 11,000 m))
p = 101325 Pa * (T / 288.15 K)^5.25588
rho_ratio = (p / 101325 Pa) * (288.15 K / T)
```

Altitude in feet is converted to metres before evaluation. The expected engine channels are simple smooth functions of the operating point:

```text
throttle' = clamp(throttle, 0.15, 1)
rpm_expected = 2400 + 2300 * throttle'
rpm_load = clamp((rpm_measured - 2400) / 2300, 0, 1)
CHT_expected = ambient_C + 120 + 20 * throttle' + 20 * rpm_load - 12 * (1 - rho_ratio)
EGT_expected = 440 + 330 * throttle' + 100 * rpm_load - 38 * (1 - rho_ratio)
fuel_expected = 4 + 24 * (0.65 * throttle' + 0.35 * rpm_load) * rho_ratio
oil_expected = 45 + rpm_measured / 180 + 6 * throttle'
```

The engine simulator uses a first-order lag, `x(t+dt) = x(t) + (target - x(t)) * (1 - exp(-dt/tau))`, with a 12 second thermal time constant and a 2 second response for the other channels. Sensor noise is generated by a seeded Box-Muller normal sampler. Scenario magnitudes and noise sigmas are prototype assumptions in `src/sim/engine.ts` and `src/sim/physics.ts`.

For each measured channel, the standardised residual is `(measured - expected) / sigma`. The current fixed sigma values are RPM 55, CHT 3.5 C, EGT 8 C, fuel flow 0.8 L/h, and oil pressure 2.5 psi. The high-altitude expected values include density and ambient-temperature terms, so a climb is compared to a moving baseline instead of the sea-level alarm limits.

## Detection and component attribution

At worker startup, an Isolation Forest is built from seeded healthy residual samples at varied altitude, throttle, and ambient-temperature operating points. Each tree uses random feature selection and random split points. Its score is `2^(-mean_path_length / c(sample_size))`. Mechanical evidence is confirmed only after five consecutive 10 Hz windows. Isolated CHT residuals are classified as `SENSOR CHECK` when exhaust and fuel-flow residuals remain quiet. That path does not decrease the engine health index.

The virtual injector fault uses expected CHT/fuel-flow residual signatures for four cylinder ids. The signature mapping exists only to exercise component visualization in this demo. Lubrication loss is attributed from its oil-pressure channel; an isolated CHT sensor drift is shown as cooling/sensor status.

## Health, remaining useful life, and mission reliability

Health is bounded from 0 to 100 and starts at 100 for a new browser simulation. Persistent mechanical faults decrease health by 0.00035 points per 10 Hz update. A simple linear fit over the recent health trend estimates the rate per flight hour. Remaining useful life projects that trend to health 30. A flat or short trend is shown as `INSUFFICIENT TREND`. The plotted lower and upper bounds widen with forecast distance as an illustrative confidence cone, not a calibrated statistical interval.

Mission reliability uses `exp(-hazard_per_hour * mission_hours)`, with a default six-hour horizon and a prototype hazard model based on health and detector status. Recommendation cutoffs are `CONTINUE` at 90 percent and above, `CAUTION` below 90 percent, and `RETURN` below 65 percent or health below 45. These values are configurable assumptions, not operational guidance.

## Edge packet and bandwidth estimate

The health vector is encoded with `DataView` into a fixed 32-byte packet once per second. Eight bytes are reserved for protocol framing and checksum overhead inside that size. Raw frame accounting assumes a 36-byte timestamp-plus-eight-channel record sampled ten times each second, or 360 bytes/s. A 32-byte/s transmitted vector therefore yields `(1 - 32 / 360) * 100 = 91.1 percent` estimated bandwidth saved. The badge is computed from the byte counters accumulated by the worker, so actual counter intervals can cause small rounding variation.
